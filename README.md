# HAPAning 🦄 - AI Finance Dashboard

A Gen Z focused, simulated finance dashboard featuring Glassmorphism design and AI-powered insights.

## Features

### 1. Sector Heat Map 🔥
- Live visualization of market sectors.
- Green/Red/Yellow indicators based on performance.
- Hover for detailed stats.

### 2. AI Fund Allocation 🤖
- Smart portfolio allocator.
- Inputs capital and suggests sector split based on market momentum and "AI Confidence".
- Visualized with a Doughnut chart.

### 3. TWAP Simulator ⏳
- Simulates Time-Weighted Average Price execution.
- Visualizes how splitting orders over time can reduce volatility impact vs. lump sum buying.
- educational tool for beginners.

## Tech Stack
- **Core:** HTML5, CSS3 (Glassmorphism), Vanilla JavaScript (ES6+).
- **Libraries:** Chart.js (for graphs), FontAwesome (icons), Google Fonts.
- **Data:** Simulated locally in `js/data.js` (No backend required).

## How to Run
1. Simply open `index.html` in any modern web browser.
2. For the best experience, use a local server (like Live Server in VS Code) to ensure fonts and external scripts load correctly without CORS issues.

## Design
- **Theme:** Dark Mode + Neon Accents + Frosted Glass.
- **Font:** Outfit & Space Grotesk.
